# Suárez Somonte Roman hare-hunt mural, Mérida

## Object identity

The Spanish Ministry of Culture's CER.es record for the Museo Nacional de Arte Romano identifies inventory **CE37404** as a Roman mural-painting ensemble from Calle Suárez Somonte, Mérida.

- Institution: Museo Nacional de Arte Romano (MNAR)
- Inventory: CE37404
- Object: mural painting on stucco
- Technique: fresco
- Dimensions: 2.10 m high; 6.75 m long; 5.90 m wide
- Provenance: Calle Suárez Somonte, Mérida
- Cultural context: Bajo Imperio
- Catalog dating: 301–400 CE
- Official object URL: https://ceres.mcu.es/pages/Main?idt=7169&museum=MNAR&table=FMUS

## What the official record says

The museum record describes a room decorated with hunting and circus scenes. Five panels survive, including a charioteer, horse training, deer hunting and **hare hunting**.

The official object record therefore directly establishes a hare-hunting scene in a late Roman domestic/iconographic context at Augusta Emerita.

## Evidence classification

### Supported directly

- Roman-period hare-hunting imagery is securely attested in Mérida.
- The object belongs to an officially catalogued late Roman mural ensemble.
- Hunting imagery formed part of elite/domestic visual culture in Roman Hispania.

### Supported only with attribution to later scholarship

Some modern Spanish archaeological and art-historical descriptions use terms such as `lebrel` or sighthound when interpreting comparable hare-hunting dogs. The current CER.es object metadata itself should **not** be paraphrased as formally identifying this panel's dog as a Galgo Español.

### Not supported

This object does not establish:

- that the depicted dog belonged to the modern Galgo Español breed;
- a pedigree or documented population bridge from Roman dogs to modern galgos;
- genetic continuity;
- formal breed identity in antiquity.

Visual resemblance is not population evidence.

## Continuity dimensions

- Function: **strong** — hare hunting is directly represented.
- Type: **limited visual evidence** — morphology may be described, but visual type cannot establish ancestry.
- Population: **none**.
- Name: **none for the dog in the official object record**.

## Research conclusion

Suárez Somonte is a strong Roman-Iberian visual anchor for hare-hunting culture. It should be used to document function and material culture, not to retroactively assign a modern breed identity.
