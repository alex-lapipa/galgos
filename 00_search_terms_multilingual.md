# Multilingual Search Terms and Terminology

## Core term set

| Term | Language | Notes |
|---|---|---|
| galgo / galga / galgos | Castilian | Modern and medieval; etymology traditionally linked to *canis gallicus* ("Gallic dog") — to be verified per period, not assumed |
| lebrel / lebrero / leporario | Castilian | From *lepus* (hare); "hare-dog" |
| perro corredor / perro de liebre | Castilian | Descriptive, not necessarily a breed name |
| alano | Castilian | A distinct type (mastiff-like, not a sighthound) — included to avoid conflation |
| podenco | Castilian | A distinct Iberian hunting type, scent/sight hybrid use — included to avoid conflation |
| traílla | Castilian | Leash/coupling term relevant to coursing law |
| caza de liebre / correr la liebre | Castilian | Hare hunting / coursing |
| venación / montería | Castilian | General hunting / big-game hunting terminology |
| canis gallicus | Latin | "Gallic dog" |
| canis celticus | Latin | "Celtic dog" |
| canis leporarius | Latin | "Hare-dog" |
| vertragus / vertragi | Latin (from Celtic) | Term used by Arrian/Grattius for Celtic swift hound |
| greyhound | English | Modern breed name; historical usage broader than modern breed |
| lévrier | French | Sighthound |

## Search strategy notes

- Search historical Castilian and Leonese spelling variants (e.g. *galgo/galgos* appears in mixed orthography in medieval fueros; also check *galgu*, *galgo(s)* with abbreviations common in scribal Latin-Castilian hybrid documents).
- Treat "galgo" as primarily an early functional/descriptive term historically, only later formalized as a breed name — this must not be assumed backward onto Roman-era sources.
- Etymological claims (e.g. galgo < *canis gallicus*) are documented as **traditional/etymological claims** unless supported by historical linguistics scholarship (checked against CORDE / Diccionario histórico and academic etymological dictionaries), not asserted as fact.
